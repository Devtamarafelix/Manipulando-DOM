Conhecendo o DOM

O que é o DOM?

O DOM (Document Object Model) é uma representação da página HTML que o navegador cria na memória.

Ele permite que JavaScript leia, altere, adicione e remova elementos da página.

Conexão dos elementos:

  • HTML: É o arquivo que você escreve
  • DOM: É a arvore de objetos que navegador cria a partir desse HTML
  • JavaScript: Usa o DOM para interagir com a página
