# 🚀 Projetos Front-End — Módulo de Manipulação da DOM | Curso Transforme-se (Instituto PROA/Serasa Experian)

Este repositório contém as práticas e projetos desenvolvidos especificamente no **módulo de manipulação da DOM** das aulas de Front-End do curso **Transforme-se**, oferecido pelo **Instituto PROA** e **Serasa Experian**.

---

## 🎯 Objetivo do Módulo

O objetivo principal desta etapa do curso foi praticar a **manipulação da DOM (Document Object Model)** com JavaScript puro, aprendendo a capturar elementos, escutar eventos do usuário, alterar estilos dinamicamente e atualizar o conteúdo da página em tempo real.

---

## 📌 Funcionalidades Desenvolvidas

* 🍔 **Menu Hambúrguer Responsivo:** Toggle de classes via JS para abrir e fechar o menu em telas menores.
* 🌗 **Fundo Dinâmico por Horário:** Alteração de estilos do fundo via JS em tempo real, baseando-se no horário do sistema.
* 📝 **Lista de Tarefas (To-Do List):** Criação e remoção dinâmica de elementos HTML na DOM a partir dos inputs do usuário.
* 👾 **Pokédex (PokéAPI):** Consumo de API assíncrona (`fetch`) e renderização dos dados e imagens do Pokémon diretamente na página.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estruturação semântica da página.
* **Tailwind CSS** — Estilização moderna e ágil utilizando classes utilitárias e design responsivo.
* **JavaScript (ES6+)** — Manipulação da DOM, consumo de APIs (`fetch`), funções assíncronas e controle de tempo (`setInterval`).
